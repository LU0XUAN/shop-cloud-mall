一、模块概述

📋 模块定位

订单模块是电商系统的核心业务模块之一，负责处理用户下单、订单状态流转、订单查询、销量统计等功能。该模块基于 Spring Cloud 微服务架构，独立部署为 shop-modules-order 服务，通过 Nacos 进行服务注册与发现。

4.2 SysOrderServiceImpl（实现类）

实现了自定义的 getMyOrder() 方法，用于获取当前登录用户的订单列表。

package com.shop.order.service.impl;

import com.baomidou.mybatisplus.extension.service.impl.ServiceImpl;
import com.shop.order.mapper.SysOrderMapper;
import com.shop.order.service.SysOrderService;
import com.shop.security.utils.SecurityUtils;

@Service
public class SysOrderServiceImpl 
    extends ServiceImpl<SysOrderMapper, SysOrder> 
    implements SysOrderService {

    @Override
    public List<SysOrder> getMyOrder(SysOrder item) {
        // 开启分页
        PageUtils.start();
        
        // 使用LambdaQuery链式查询
        return this.lambdaQuery()
            // 按创建人ID筛选（当前登录用户）
            .eq(SysOrder::getCreateBy, SecurityUtils.getUserId())
            // 按商品名称模糊查询（条件可选）
            .like(item.getName() != null, SysOrder::getName, item.getName())
            // 按状态筛选（条件可选）
            .eq(item.getStatus() != null, SysOrder::getStatus, item.getStatus())
            // 按创建时间倒序
            .orderByDesc(SysOrder::getCreateTime)
            .list();
    }
}
关键点：
- SecurityUtils.getUserId()：从JWT Token中解析当前登录用户ID
- lambdaQuery()：MyBatis Plus的Lambda查询，类型安全
- like(condition, field, value)：条件查询，第一个参数为条件判断

5.2 核心API详解：新增订单

这是订单模块最核心的接口，实现了从购物车到订单的转换逻辑。

@PostMapping
@Log(describe = "新增订单")
public R<?> add(
    @RequestBody List<Map<String, Object>> items,
    @RequestParam(required = false) Boolean useIntegrals,
    @RequestParam(required = false) Integer point) {
    
    // 1. 获取当前登录用户ID
    Long userId = SecurityUtils.getUserId();
    
    // 2. 生成订单号前缀（DD-时间戳-）
    String orderPrefix = "DD-" + System.currentTimeMillis() + "-";
    
    // 3. 遍历购物车商品列表
    for (int i = 0; i < items.size(); i++) {
        Map<String, Object> item = items.get(i);
        Integer cid = toInteger(item.get("cid"));
        Integer aid = toInteger(item.get("aid"));
        
        // 4. 根据购物车ID查询购物车信息
        SysCart cart = cartMapper.selectById(cid);
        if (cart == null) continue;
        
        // 5. 创建订单对象，复制购物车信息
        SysOrder order = new SysOrder();
        order.setCreateBy(userId);
        order.setPid(cart.getPid());
        order.setAid(aid);
        order.setName(cart.getName());
        order.setPrice(cart.getPrice());
        order.setSum(cart.getSum());
        order.setNum(cart.getNum());
        ...
        
        // 6. 生成唯一订单号
        String numbers = orderPrefix + (i + 1);
        order.setNumbers(numbers);
        order.setStatus("0"); // 0:已下单
        
        // 7. 计算积分（消费1元得1积分）
        BigDecimal price = new BigDecimal(finalPrice);
        order.setIntegral(String.valueOf(price.intValue()));
        
        // 8. 保存订单
        orderService.save(order);
    }
    return R.ok();
}
订单号生成规则：
DD-{时间戳}-{序号}
示例：DD-1625097600000-1
5.3 核心API详解：商品销量统计

统计所有订单中各商品的销量，返回TOP10数据，用于图表展示。

@GetMapping("/productStats")
@Log(describe = "商品销量统计")
public R<?> productStats() {
    // 1. 查询所有订单
    List<SysOrder> allOrders = orderService.lambdaQuery().list();
    
    // 2. 按商品名称分组统计销量
    Map<String, Integer> salesMap = new HashMap<>();
    for (SysOrder order : allOrders) {
        String name = order.getName();
        Integer num = order.getNum();
        salesMap.put(name, salesMap.getOrDefault(name, 0) + num);
    }
    
    // 3. 转换为EchartsVo格式
    List<EchartsVo> result = new ArrayList<>();
    for (Map.Entry<String, Integer> entry : salesMap.entrySet()) {
        EchartsVo vo = new EchartsVo();
        vo.setName(entry.getKey());
        vo.setValue(entry.getValue());
        result.add(vo);
    }
    
    // 4. 按销量排序，取前10
    result.sort((a, b) -> b.getValue() - a.getValue());
    if (result.size() > 10) {
        result = result.subList(0, 10);
    }
    
    return R.ok(result);
}
5.4 核心API详解：修改订单状态

支持订单状态的流转操作。

@PutMapping("/editStatus")
@Log(describe = "修改订单状态")
public R<?> editStatus(@RequestBody SysOrder item) {
    SysOrder order = new SysOrder();
    order.setId(item.getId());
    order.setStatus(item.getStatus());
    return R.ok(orderService.updateById(order));
}

八、关键技术与设计亮点

8.1 MyBatis Plus Lambda查询

使用Lambda表达式进行类型安全的查询，避免字符串硬编码字段名。

// Lambda查询 - 类型安全
this.lambdaQuery()
    .eq(SysOrder::getCreateBy, userId)
    .like(item.getName() != null, SysOrder::getName, item.getName())
    .orderByDesc(SysOrder::getCreateTime)
    .list();

// 传统方式 - 容易出错
queryWrapper.eq("create_by", userId)
    .like("name", item.getName());

8.4 安全认证

通过JWT Token进行认证，SecurityUtils.getUserId() 从Token中解析用户ID。

认证流程：
1. 用户登录获取JWT Token
2. 前端每次请求在Header中携带Token
3. Gateway网关拦截并验证Token
4. 后端通过 SecurityUtils.getUserId() 获取当前用户
